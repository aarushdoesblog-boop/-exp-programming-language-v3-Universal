# -exp-programming-language-v3-Universal
I had to jump from [v1.0 actual] as all the versions from 1.1 to 2.5(all the small bit of changes), weren't capable of doing complex tasks. The universal expansions have been added to all the 10 experts and, plus one other expert, @physics*, made for universal physics. Now these aren't just kiddies anymore, They're universal beasts...

Before, in the very first version(@exp v1.0 actual), the experts weren't actual experts, they were kiddies. 
Like for example, @math(10+10) will give the result as 20, but if you type: @math(2x+5=5x+2),which is a simple algebraic equation, will show an error.
But now, it is capable of doing complex mathematical tasks like: call @math(sin(a)/cos(b))
Yes, I have included commands'call' and 'run'. So when an expert is used, it is mandatory to add 'call' or 'run' before the statement.
e.g: call @math((a+b)^2)
The @penWIN expert was the most kiddy in the first version. Its brain only had the capability to execute a circle in the window. Now it is programmed to draw different shapes with different lenghts and colors.
